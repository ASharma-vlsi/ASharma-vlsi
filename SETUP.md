# Setup notes

1. Create a **public** repository named exactly after your GitHub username.
2. Upload `README.md` and the `assets/` directory from this bundle.
3. In `README.md`, replace every `USERNAME` with your actual GitHub username.
4. Add links to your real project repositories in the Featured Work section.
5. Optional: add `.github/workflows/snake.yml` using the YAML included in the README. Enable GitHub Actions and let the workflow run once.
6. Check the profile on GitHub and confirm the external stats widgets load.

The IC layout SVGs are original conceptual illustrations for a profile page, not process-accurate physical-design results.
